# Políticas Organizacionais do Repositório

As seguintes diretrizes são obrigatórias para a conformidade do repositório:

1. **Documentação Mínima Obrigatória:**
   - O repositório deve conter `README.md`, `LICENSE`, `CONTRIBUTING.md` e a pasta `docs/` estruturada.
2. **Segurança de Credenciais:**
   - É estritamente proibido incluir arquivos `.env`, `credentials.json`, chaves privadas `.pem`/`.key` ou segredos em texto claro no código versionado.
3. **Padrão de Qualidade:**
   - Todo código deve passar nas checagens estáticas e testes automatizados.
